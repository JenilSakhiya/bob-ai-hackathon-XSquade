# Solution Overview

CyberSentinel delivers a complete end-to-end autonomous security investigation workflow:

1. **Telemetry Ingestion**: Monitors simulated enterprise security logs including authentication attempts, device registrations, privilege changes, process executions, and network data transfers.
2. **Deterministic Detection Engine**: Evaluates rule-based thresholds without black-box opacity.
3. **Multi-Vector Correlation**: Clusters related alerts across common entities into cohesive incidents within a 30-minute operational window.
4. **Transparent Risk Scoring**: Calculates 0–100 scores with itemized factor evidence.
5. **AI Investigation & Hypothesis**: Automatically formulates MITRE ATT&CK hypotheses and plain-English danger assessments.
6. **Prescriptive Response Actions**: Recommends non-destructive containment actions.
7. **Incident Grounded Chat**: Answers analyst inquiries strictly grounded in incident evidence.
8. **Incident Report Generator**: Generates exportable TLP:AMBER reports in Markdown and JSON.
